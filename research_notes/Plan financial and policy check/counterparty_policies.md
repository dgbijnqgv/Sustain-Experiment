# Counterparty policies and fees (researched 2026-10-08)

Source quality: **[P]** = I read the primary text (mostly through GitHub mirrors of the official docs, because docs.github.com, metaculus.com, apify.com, openrouter.ai, ted.europa.eu, sam.gov and gov.uk were blocked by the egress proxy). **[S]** = search-engine snippet or third-party summary only. This is not legal or tax advice.

## 1. GitHub Actions (bot (A))

- **[P] Additional Product Terms, Actions section** (Version Effective Date: Aug 27, 2026; mirror: raw.githubusercontent.com/github/docs/main/content/site-policy/github-terms/github-terms-for-additional-products-and-features.md, live: https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features). Actions "should not be used for":
  - "Any activity that places a burden on our servers, where that burden is disproportionate to the benefits provided to users (for example, don't use Actions as a content delivery network or as part of a serverless application, but a low benefit Action could be ok if it's also low burden); or"
  - "If using GitHub-hosted runners, any other activity unrelated to the production, testing, deployment, or publication of the software project associated with the repository where GitHub Actions are used."
  - Enforcement: "GitHub may monitor your use … Misuse … may result in termination of jobs, restrictions in your ability to use GitHub Actions, disabling of repositories created to run Actions in a way that violates these Terms, or in some cases, suspension or termination of your GitHub account."
  - AUP (§4) also bans "excessive automated bulk activity … undue burden on our servers".
- **Assessment:** this is a grey area. A repo whose software project *is* the bot, with the workflow deploying and running it, is arguably "deployment" of that project. One hourly job is low burden. Still, the terms do not clearly endorse using Actions as a production cron host. The Metaculus official template (github.com/Metaculus/metac-bot-template, README [P]) tells users to fork the repo and run the bot through Actions every 20 minutes (cron `7,27,47 * * * *`), so the practice is widespread and accepted in that community. **[S]** I found no documented case of enforcement against a Metaculus or cron bot.
- **[P] Minutes** (github/docs reusables `actions-included-quotas.md`, `actions-standard-runner-prices.md`; live: https://docs.github.com/en/billing/concepts/product-billing/github-actions):
  - Free (personal) plan: 2,000 min/month, 500 MB artifact storage, 10 GB cache per repo. These limits apply to private repos only.
  - "free for self-hosted runners and for public repositories that use standard GitHub-hosted runners."
  - Overage per minute: Linux 2-core x64 `$0.006`, Linux 1-core "slim" `$0.002`, Linux arm64 `$0.005`, Windows `$0.010`, macOS `$0.062`. Minutes are rounded up to whole minutes for each job.
  - "If your account does not have a valid payment method on file, usage is blocked once you use up your quota."
  - Budget: an hourly run is about 720 jobs per month, so a 2-minute job uses about 1,440 minutes and a 3-minute job uses about 2,160 (over quota).
- **[P] Caveats** (github/docs events doc): schedule runs "can be delayed during periods of high loads … High load times include the start of every hour … some queued jobs may be dropped". Scheduled workflows are auto-disabled after 60 days of no activity **only in public repos**, and are disabled by default in forks. Forks of the public template are public. A private repo needs a fresh repo (template copy), not a fork.

## 2. Metaculus FutureEval

- **[P] AIB contest rules** (github.com/Metaculus/metaculus `front_end/src/app/(main)/aib/contest-rules/page.tsx`. This text is headed "Q3" (2024), so it may be stale. Live page: https://www.metaculus.com/aib/contest-rules/):
  - "Bots may not have a human in the loop when forecasting. This includes running a bot on questions that are open or upcoming in the competition, seeing the bot's output, and then modifying the bot to improve its output."
  - Participants warrant that the bot "comprises only and exclusively software code that is either (i) the original work of a person collaborating on or contributing to that bot or (ii) legally permitted to be used in that bot". AI-written code is not addressed explicitly. It most plausibly falls under (ii) (the owner holds rights to the output). See the Anthropic terms note in anthropic_policy.md.
  - Other requirements: one bot per individual; a comment on every forecasted question; the code or a description must be provided; "Prize recipients will be required to verify their identity, nationality, and residency … Taxes and fees are paid by recipients." Excluded jurisdictions: Crimea, Cuba, Iran, Syria, North Korea, Sudan, Russia.
- **[P] FutureEval page strings** (`front_end/messages/en.json`): "No human in the loop"; "One prize-eligible bot per user"; "share code or a description … allow a member of Metaculus to inspect their code."
- **AI coding agent:** no rule bans AI-written or AI-maintained bot code. The template ships a "Claude Code skill" and the README suggests "Asking an LLM to read through everything". **Risk:** if the owner or the agent looks at the bot's outputs on *open tournament* questions and then edits the bot, that is the "human in the loop" violation (the owner is directing it). Changes should be driven only by resolved or closed questions and the unscored test area. **[S]** The Fall 2026 announcement says new entrants may "improve it over the course of the tournament".
- **[P] General Competition Rules** (Last Modified Jun 13, 2025; https://www.metaculus.com/tournament-rules/): to be paid, winners must provide "(a) eligibility certifications or proof of identity; (b) U.S. tax forms (such as IRS Form W-9 if U.S. resident, IRS Form W-8BEN if foreign resident …); (c) payment delivery information, such as bank account information … via a third-party service". Payment may be cash or a cash equivalent (prepaid virtual cards and similar). If the winner does not respond, the prize is forfeited after the shorter of the stated deadline or 180 days.
- **[P] Minimum prize:** in the Metaculus code, `minimum_prize_amount` defaults to `$50.00` (scoring/models.py) and smaller shares are redistributed upward.
- **[S] only:** payment by bank transfer via **Ramp**, with a 30-day claim window and a mandatory bot-maker survey (third-party README github.com/Bowen1314/metaculus-bot). No official source confirmed this.
- **[S] Withholding for non-US winners:** I found no Metaculus statement. The usual US rule is that a US-source prize paid to a nonresident alien carries 30% withholding and is reported on Form 1042-S. A treaty "other income" article may reduce this, claimed via W-8BEN. Many payors refuse treaty claims on prizes (IRS powwow-prize page, university guidance).

## 3. Apify Store (actors (B))

- **[P] Store Publishing Terms**, last updated Sep 15, 2026 (github.com/apify/apify-docs `sources/legal/latest/terms/store-publishing-terms-and-conditions.md`; live https://docs.apify.com/legal/store-publishing-terms-and-conditions):
  - §10.2.1: payout = "80% of the fees paid by Users for your Actor, minus Platform usage costs for the corresponding Actor runs"; Apify keeps 20%.
  - §10.1.2: KYC is required, which "may include … government-issued identification, proof of address, tax documentation, and ultimate beneficial ownership information". A payout withheld for failed KYC is forfeited after 12 months.
  - §10.3.2: minimum payout is "USD 20 for PayPal and USD 100 for any other payout option". Balances below the minimum roll over and are forfeited after 12 months. The docs page (monthly-payouts.mdx) says "$20 for PayPal and Wise", which conflicts with the terms. The docs also say SWIFT transfers from CZ use SHA cost-sharing, intermediary fees are typically $10–$50, and there is no ACH to the US. A negative-profit PPE actor is set to $0 for the month.
  - §2.2.4: "You may create and publish an Actor of any kind" if it complies with the terms, the AUP and law. §3.4: you warrant you "own or have obtained all rights necessary". §5: third-party API costs are yours. §3.3: Apify may inspect source code. §2.2.1: no suggestion of official affiliation with a trademark owner (relevant to naming actors "TED", "SAM.gov", "Find a Tender").
  - AUP (Feb 20, 2026) bans activities that "contravene applicable laws, regulations, or the rights of any third party". There is no rule specific to data republishing. The Standard Actor Contract puts compliance of Output use on the end user (§2.2) and has an EU AI Act clause (§6).
- **AI-generated actors:** no prohibition. Apify publishes a "Build Actors with AI" guide covering Claude Code and AGENTS.md ([P], apify-docs `build-with-ai.md`).
- **VAT and tax forms:** [P] Apify is a Czech VAT payer for fees users pay. I found no Apify source on W-9/W-8BEN or on VAT on creator payout invoices; only "tax documentation" under KYC. Apify is non-US, so expect no 1099. [S] Self-billing and reverse charge treatment is unconfirmed; ask Apify support.

## 4. Data licences

- **EU TED** — [S] TED legal notice (https://ted.europa.eu/en/legal-notice): "procurement notices published in the Supplement to the Official Journal can be freely reused, for commercial or non-commercial purposes", under the Commission reuse Decision of 12 Dec 2011 (2011/833/EU). Editorial content is CC BY 4.0. [S] Decision conditions: acknowledge the source, do not distort the meaning, no Commission liability. The 2019 Commission decision made CC BY 4.0 the default; I did not confirm the number 2019/1372. Suggested credit: "Source: TED – Publications Office of the European Union, ted.europa.eu", with changes indicated. [S] The API allows anonymous search. Fair-usage limits (https://ted.europa.eu/en/news/fair-usage-policy-on-ted): 600 notices viewed or downloaded per IP per 6 min, 700 HTTP requests per minute, 3 concurrent package downloads.
- **UK Find a Tender / Contracts Finder** — [S] FTS docs: "Notice data is available under the Open Government Licence" (https://www.find-tender.service.gov.uk/Developer/Documentation). [P] OGL v3 text (SPDX mirror): you must "acknowledge the source … by including or linking to any attribution statement specified by the Information Provider(s) and, where possible, provide a link to this licence". The default statement is: **"Contains public sector information licensed under the Open Government Licence v3.0."** Personal data is excluded, and "non-endorsement" applies (no implying official status). I found no service-specific statement, so use the default line plus a link to https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/. [S] No published rate limits.
- **SAM.gov** — [P] Opportunities API doc (GSA/open-gsa-redesign): an API key is required, and daily request caps vary by role. [S] Third-party figures are about 10/day for a personal account without a role and 1,000/day for an entity or system account. [S] sam.gov Terms of Use (https://sam.gov/about/terms-of-use): "Do not share your individual account API key with anyone"; "If you want to share data publicly, only share data from public versions of APIs"; automated scraping of the web UI is prohibited; keys rotate every 90 days. I found no clause banning commercial redistribution of public Opportunities data. US federal works are generally public domain (GSA site notice) [S]. D&B fields in the Entity API are restricted, but Opportunities does not include them. **Risk:** a user-supplied key is that user's key, so the actor must not embed or share the owner's key.

## 5. OpenRouter

- [P] Docs repo github.com/OpenRouterTeam/docs (`faq.mdx`, `snippets/exports/constants.mdx`):
  - Card purchases: **5.5% ($0.80 minimum)**. Crypto: **5%**. No markup on inference.
  - BYOK: free up to $25,000 list-price per month, then 5%.
  - Credits: refundable within 24 h; platform fees are non-refundable; crypto is never refundable; OpenRouter "reserve[s] the right to expire unused credits after one year".
- [S] Terms (via conductatlas.com): bans reselling or building a competing service, and "automated access beyond reasonable human rates". Normal API use by your own bot is the intended use. Metaculus-donated credits are delivered through OpenRouter and must be used for the tournament [S].

## 6. Taxes (flag only; get professional advice)

- **US prize:** taxable as "other income" (Schedule 1). It is generally not SE income unless forecasting is a trade or business. **1099-MISC threshold is $2,000 for payments after Dec 31, 2025** (OBBBA §70433) [S, multiple tax-firm sources], not $600. It remains taxable below the threshold.
- **Apify payouts (US person):** business or self-employment income (Schedule C plus SE tax if net ≥ $400). Apify (CZ) will likely not issue a 1099. PayPal may issue a 1099-K only above $20k and 200 transactions [S].
- **Non-US:** depends on the country. Metaculus prize: possible 30% US withholding unless a treaty applies (W-8BEN). Apify income is taxed under local self-employment or VAT rules. EU VAT-registered sellers: check reverse charge.
